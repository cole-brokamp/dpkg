# Package index

## using a dpkg

- [`dpkg_meta()`](http://geomarker.io/codec/reference/dpkg_meta.md) :
  get the metadata associated with a data package
- [`read_dpkg_metadata()`](http://geomarker.io/codec/reference/read_dpkg.md)
  [`read_dpkg()`](http://geomarker.io/codec/reference/read_dpkg.md) :
  read (meta)data from dpkg on disk

## creating a dpkg

- [`as_dpkg()`](http://geomarker.io/codec/reference/as_dpkg.md) : Use a
  data.frame and metadata to create a data package
- [`write_dpkg()`](http://geomarker.io/codec/reference/write_dpkg.md) :
  write dpkg to disk
- [`dpkg_gh_release()`](http://geomarker.io/codec/reference/dpkg_gh_release.md)
  : Use a dpkg to create a github release
- [`use_dpkg_badge()`](http://geomarker.io/codec/reference/use_dpkg_badge.md)
  : Use a markdown badge for a dpkg's latest github release
